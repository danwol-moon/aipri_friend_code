# 프렌즈 카드 모음

여러 사용자가 프렌즈 카드를 등록하고 검색할 수 있는 프리티시리즈 유저가 만든 비공식 사이트입니다.
공식과 무관함을 말씀드립니다.



## 이용 가이드
- 우측 상단에 있는 `+ 프카 이미지 등록` 버튼을 누릅니다.
- 좌측에는 프렌즈 카드 이미지를, 우측에는 코디 이미지를 업로드합니다. (이미지는 프렌즈 카드 이미지만 올려도 무관합니다.)
- 프렌즈 카드의 코디 이름을 적습니다. (이름 또한 한국어/일본어 둘 중 한 가지만 적어도 무관합니다.)
- X 닉네임/ID, 마이캐릭터 이름를 입력하고 태그를 선택합니다. 이때 빈칸으로 등록할 수도 있습니다.
- 등록/수정/삭제할 때에 `비밀번호`가 필요합니다. 잊지 않게 잘 기억해주세요.



## 검색/이로치
- 상단에 있는 검색창에서 코디 이름 등을 입력하여 원하는 프렌즈 카드를 찾을 수 있습니다.
- 등록된 프렌즈 카드를 클릭하면 비슷한 코디, 이로치 등을 한 번에 확인 할 수 있습니다. (정확한 기능이 아닙니다.)



## 관리자 모드
- 관리자 모드란, 비밀번호를 분실 시 관리자가 비밀번호 변경 등을 할 수 있는 모드입니다. 이 모드는 현재 제작자만 기능을 사용 할 수 있습니다.
- 관리자 모드가 활성화 되어 있을 때는 비밀번호를 입력하지 않아도 등록된 프렌즈 카드를 수정, 삭제 할 수 있습니다.
